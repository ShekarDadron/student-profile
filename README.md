Student Profile Appis a clean, modern Android application developed in Kotlin using Material Design 3 components.

Features
- **Material Design 3:** Custom card views, outlined floating-label inputs, and circular avatar framing.
- **Profile Details:** Manages Full Name, Student ID, Programme, Department, Semester, Email, and Phone Number.
- **Action Buttons:** Interactive **Save**, **Clear**, and **Edit** buttons with toast notifications.
- **Responsive Layout:** Scrollable `ConstraintLayout` supporting edge-to-edge system insets.

## Tech Stack
- **Language:** Kotlin
- **UI:** XML Layouts, Material Design 3, ConstraintLayout
- **IDE:** Android Studio
